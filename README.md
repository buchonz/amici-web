# Amici — Restaurant Website (Demo)

One-page demo website for **Amici**, a restaurant on Church Street,
Georgetown, Guyana. Built for a business proposal pitch.

## What's inside

- Single self-contained `index.html` (HTML + CSS + vanilla JavaScript, no dependencies)
- Dark elegant "trattoria" theme, EN/IT language switcher (saved in localStorage)
- Interactive Google Maps embed (public iframe, **no API key required**)
- Auto "Open now / Closed" badge computed from the hours table
- Scroll animations, parallax hero, photo lightbox, 5-star review block

## How to view

Just open `index.html` in any browser. No build step, no install.

## Notes

- Placeholder content (menu, prices, reviews, phone) must be replaced
  with real data before publishing.
- Stock photos are from Unsplash (demo only) — replace with the
  restaurant's own photos before going live.
